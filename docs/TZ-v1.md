# NeoPos — техзадание на первую версию

Система автоматизации для кафе и ресторанов. Первая версия состоит из трёх частей:
панель управления, терминал продаж и Telegram-бот с отчётами для владельца.

Дата: 21.11.2026. Статус: черновик на согласование.

## 1. Что входит и что не входит

| Входит в первую версию | Отложено |
|---|---|
| Панель управления (веб) | Склад, тех. карты, ингредиенты, поставки |
| Терминал продаж (веб, планшет или ПК) | Приложение официанта, кухонный экран |
| Telegram-бот с отчётами | QR-меню, программа лояльности |
| Узбекский и русский языки | Фискальная касса, интеграции с доставкой |
| Одно заведение = один аккаунт, несколько филиалов | Работа без интернета, отдельное мобильное приложение |

Структура данных сразу закладывается так, чтобы склад и остальные модули можно было
добавить позже без переделки (товар уже имеет тип, отдел и единицу измерения).

## 2. Роли

- **Владелец** — полный доступ к панели, получает отчёты в Telegram.
- **Администратор / менеджер** — панель по выданным правам, действия на терминале, требующие подтверждения.
- **Кассир / официант** — только терминал, вход по ПИН-коду.

Права задаются через должности: доступ к панели, доступ к терминалу и отдельные
разрешения (скидка, удаление позиции, возврат, изменение цены, открытие закрытого чека).

## 3. Панель управления

**Меню**
- Категории (с вложенностью, цвет, картинка, порядок).
- Товары: название на двух языках, цена, категория, отдел, штрих-код, картинка, продажа на вес, активен/скрыт.
- Модификаторы: наборы с минимумом и максимумом выбора, доплата за вариант.
- Отделы (кухня, бар) — на какой принтер уходит заказ.
- Массовое изменение цен, импорт и экспорт меню через Excel.
- Стоп-лист: временно снять товар с продажи.

**Залы и столы**
- Залы, столы с номером и количеством мест, расположение на схеме.

**Продажи**
- Способы продаж: в зале, с собой, доставка. Для каждого — своя плата за обслуживание.
- Способы оплаты: наличные, карта, перевод (Click, Payme), смешанная.
- Список чеков с фильтрами, детали чека, история действий по чеку.
- Причины удаления позиций и возвратов (справочник).
- Скидки: процент или сумма, на товар или на весь чек.

**Сотрудники**
- Сотрудники, должности, права, ПИН-код для терминала.

**Клиенты**
- База клиентов: имя, телефон, заметка, история чеков. Без бонусов.

**Отчёты**
- Сводка: выручка, количество чеков, средний чек, гости — за день, неделю, месяц, произвольный период.
- По товарам, категориям, сотрудникам, способам оплаты, способам продаж, столам, часам дня.
- Скидки, удаления, возвраты — отдельным отчётом.
- Кассовые смены: открытие, закрытие, внесения, изъятия, расхождение.
- Экспорт в Excel.

**Настройки**
- Данные заведения, филиалы, валюта (сум), шаблон чека с логотипом, принтеры, терминалы.
- Подозрительные действия: что помечать (удаление после печати, скидка выше порога, возврат).

## 4. Терминал продаж

- Вход по ПИН-коду, автоматический выход при бездействии.
- Открытие и закрытие кассовой смены с пересчётом наличных; внесение и изъятие денег.
- Схема зала: столы с цветом по статусу (свободен, занят, счёт распечатан).
- Быстрая продажа без стола (с собой, доставка).
- Чек: добавление товаров по категориям, поиск, избранное, штрих-код; количество, модификаторы, комментарий к позиции и к чеку, число гостей.
- Отправка заказа на кухню: печать по отделам, дозаказ печатает только новые позиции.
- Скидка, плата за обслуживание, угощение (позиция за 0 с причиной).
- Перенос чека на другой стол, объединение и разделение чеков, смена официанта.
- Предчек (счёт гостю) и оплата: один или несколько способов, расчёт сдачи.
- Удаление позиции после отправки на кухню — только с причиной и по разрешению.
- Возврат закрытого чека и повторное открытие — по разрешению.
- Печать на термопринтер 80 мм через браузер; чек кассовый и кухонный.

Все действия с чеком пишутся в журнал: кто, когда, что изменил.

## 5. Telegram-бот для владельца

- Привязка: владелец в панели получает код, отправляет боту — бот привязывается к заведению. Можно привязать нескольких получателей.
- **Автоматически:** отчёт при закрытии смены (выручка, чеки, средний чек, по способам оплаты, скидки, удаления, возвраты, расхождение в кассе) и ежедневная сводка в заданное время.
- **Уведомления сразу:** удаление позиции после отправки на кухню, возврат, скидка выше порога, открытие закрытого чека. Каждое включается отдельно.
- **По кнопке:** «Сегодня», «Вчера», «Неделя», «Месяц», «Топ товаров», «По сотрудникам», «Открытые чеки сейчас».
- Язык бота — узбекский или русский, выбирается при привязке.

## 6. Техническое решение

- **Сервер:** Node.js + TypeScript, база PostgreSQL. Один сервер обслуживает панель, терминал и бота.
- **Панель и терминал:** React + TypeScript + Tailwind. Терминал — отдельное приложение, рассчитанное на сенсорный экран.
- **Бот:** в том же серверном проекте, получает события продаж напрямую.
- **Обновление в реальном времени:** изменения в чеках сразу видны на всех терминалах филиала.
- **Много заведений в одной базе:** каждое заведение видит только свои данные — это основа для продажи по подписке.
- Деньги хранятся целыми числами в сумах, время — в UTC, отображается по Ташкенту.

## 6а. Оформление

- **Терминал и экран официанта:** стиль Liquid Glass (полупрозрачные панели на цветном размытом фоне). Утверждён 21.11.2026 по макету `panel/design/terminal-variants.html`.
- **Расположение на терминале — как в Clopos:** чек слева (с узкой полоской действий), плитки категорий и блюд справа, сверху «Новый заказ» и «Чеки». Чек и меню стоят рядом на любой ширине экрана. Лишних элементов не добавляем.
- **Панель управления:** обычный светлый стиль, переключатели вместо галочек.

## 7. Порядок работ

1. Каркас проекта, база данных, вход, должности и права.
2. Меню, залы и столы в панели.
3. Терминал: смена, чек, оплата, печать.
4. Чеки и отчёты в панели, журнал действий.
5. Telegram-бот: привязка, отчёты, уведомления.
6. Два языка, Excel, проверка на реальном меню.

## 8. Что нужно решить до запуска у клиентов

- **Фискализация.** В Узбекистане продажи должны проходить через онлайн-ККМ или виртуальную кассу. В первой версии этого нет — для внутреннего учёта система подходит, для полной замены кассы потребуется интеграция.
- **Интернет.** Первая версия работает только онлайн. Режим без интернета — отдельный большой этап.
- **Договор с Clopos.** Сайт RestoranPOS представляет компанию как официального партнёра Clopos. Стоит проверить, нет ли в партнёрском договоре запрета на выпуск конкурирующего продукта.
- **Свой облик.** Название, логотип, дизайн и тексты — собственные; у Clopos берутся только общие идеи функций.
